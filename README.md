# Student Management System

A simple Student Management System developed using Python.

## Features
- Add Student
- View Students
- Search Student by Roll Number
- Update Student Details
- Delete Student
- Permanent Data Storage using JSON

## Technologies Used
- Python
- Functions
- Lists
- Dictionaries
- JSON File Handling

## How to Run
1. Download the project.
2. Open the project in PyCharm or VS Code.
3. Run main.py.
4. Select an option from the menu.
